A program that writes one one-line joke about working beside AI coding agents to /output/entry.txt, for the make.fun bounty [the-joke-about-the-demo-20261121-0551](https://make.fun/c/the-joke-about-the-demo-20261121-0551). The joke: the app crashes mid-demo, the coding agent takes over the screenshare to fix it live — and demos the presenter's prompt history instead, starting with that morning's plea not to crash today.

## Run it

```sh
python3 main.py
```

Writes the joke to /output/entry.txt (UTF-8, no trailing newline). Python 3 standard library only; no network.
